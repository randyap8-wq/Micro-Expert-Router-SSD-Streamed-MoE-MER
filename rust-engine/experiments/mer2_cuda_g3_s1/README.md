# G3-S1 P1a host-token/provider source draft

SOURCE ONLY. This candidate has not been compiled, tested, or executed. The fake CPU adapter is `SIMULATED_CPU_UNQUALIFIED`; its receipts do not establish GPU execution or physical residency. Issue #333 authorizes exactly ten new files, no Cargo.lock and no native CUDA implementation. The optional `cuda=[]` feature is a refusal placeholder. Calling the CUDA entrypoint always returns `STOP_CUDA_UNAVAILABLE`; no CPU fallback exists.

The independent two-layer host decoder performs embedding, normalization, dense attention projections, RoPE, causal attention over provisional KV, CPU observed routing, ranked aggregation, residuals and logits. All four selected expert FFNs pass through the injected provider. S0's observation hook is never used as an execution callback. Arithmetic/fixture serialization is instantiated from the sealed S0 specification to retain evaluation order; this is not an independent mathematical oracle. S0 remains a distinct read-only dev dependency for later test comparisons. Production and the root workspace are untouched.

`abi.rs` owns checked finite 64-element f32 vectors and named 2304-byte 64x64 Q4_0 matrices. Gate/up/down total 6912 bytes per expert and 55296 for eight experts: logical payload geometry only. Q4 blocks use one little-endian f16 scale and 16 nibble bytes, low j/high j+16. Typed outputs own their data, so no caller can alias mutable input/output storage. Future native allocation alignment, non-aliasing and compiled PTX profile still require separate verification.

`state.rs` is the sole sealed `FfnProvider` implementation, parameterized by an injectable `Adapter`. Every call binds session, request, nonce, attempt, position, observed rank, layer, expert, weight digests, input digest, selected weight bits, slot, nonzero generation, context and event. All eight logical resident experts are installed once, with no eviction or reload. Generations and events use checked monotonic process-local identities. One token can be outstanding across interleaved requests. Rank-specific inputs and routes cannot change between the two experts of a layer. Stable softmax selection sorts probability descending, ties by expert ID ascending, then renormalizes selected probabilities.

The shared machine submits UploadInput, Gate, Up, Silu, Multiply, Down, Readback in order. Attempted, submitted, confirmed completions and consumed FFNs are separate counters. A completion must match the exact expected operation and full lease; outputs cannot appear before Readback. The final fenced reply carries all five stage snapshots, preserving 66 host-stage receipts per token. Snapshot collection is a host interface requirement, not a measured D2H schedule: a future native provider must retain and read its actual stage outputs and prove buffer ownership. This source does not invent GPU transfer, allocation, launch timing or VRAM results.

All failures and cancellation terminally poison the request; the shared owner also fails closed. First errors survive secondary cleanup failures. One checked drain precedes checked release. Unconfirmed drain, dependency ownership or release quarantines the entire adapter with `mem::forget`, deliberately preventing unconfirmed resource destructors. The adapter contract requires retaining every asynchronous owner before a fallible API and retaining borrowed-input copies inside the owner. Native ownership or the absence of leaks cannot be established by this fake implementation. Request KV is separately owned, two-layer provisional copies commit together only after all 66 receipts and four FFNs succeed. A greedy next token is processed at p+1.

`identity.rs` requires a caller-supplied external ten-file source hash map, checks compiled and physical S1 bytes, independently reads/hashes all nine physical sealed S0 files, checks the original S0 aggregate and contract, and rejects missing or altered files. It never installs packet source copies. Each token rechecks physical source identity. Source self-report is not authorization. The accepted S0 raw logits are copied verbatim from the authenticated acceptance record; no new goldens were generated.
